# Changelog

## Version 1.1, September 2026

This update clarifies how teams should interpret and use the Supplier Stability Framework.

- Added guidance that a high Friction Index identifies a pattern for review, not proof of supplier fault.
- Added examples of internal process and data conditions that can affect delivery signals.
- Clarified the intended users as purchasing, procurement, and supplier-management teams.
- Added the public Streamlit dashboard link to the Version 1.1 scope guide.

## Version 1.0.1, September 2026

This update makes the project easier to understand for procurement and manufacturing teams who are reviewing the framework for the first time.

- Added a plain-language scope and implementation guide.
- Added clearer context around synthetic demo data.
- Added a short roadmap for criticality, partial shipments, and data confidence.
- Added a public software license.
